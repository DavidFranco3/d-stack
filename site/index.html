System Requirements

Required tools for local development.

Node.js (>= v18.0.0)

Runtime for the Express backend and Vite dev server.

node -v # v18+, v20+ or v24+ LTS

MongoDB Service

Local service on port 27017. Connects to database dstack-db.

mongod # mongodb://127.0.0.1:27017/dstack-db

npm (>= v9.0.0)

Package manager for CLI and project dependencies.

npm -v # v9+ or v10+

Architecture & Features

Key characteristics of the framework.

Layered Architecture

Separation between routes, controllers, services, and models. Each layer has a single responsibility.

TypeScript & JavaScript

Full support for both languages. Choose TS for type safety or JS for faster prototyping.

Zod Validation

Request body, query, and params validation middleware with standard error responses.

Security

Helmet HTTP headers, rate limiting, JWT authentication middleware included by default.

CRUD & Auth Generator

dstack g resource <Name> auto-injects routes & React pages with Modals & Toasts. dstack g auth scaffolds full Auth & Registration UI.

OpenAPI / Swagger UI

Built-in interactive Swagger UI documentation endpoint at /api/docs out-of-the-box.

Quick Start

Get a project running in 3 steps.

1

Install the CLI

Install the CLI globally from npm:

npm install -g @davidfranco3/dstack
2

Scaffold a Project

Generate the full-stack structure with Express API and React frontend (auto-installing dependencies):

dstack init my-app -t ts -i
3

Generate Resources & Run

Create CRUD modules and start the development servers:

cd my-app
dstack g resource Product
npm run dev
