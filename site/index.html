Requisitos Previos del Sistema

Asegúrate de contar con estas herramientas instaladas en tu entorno antes de comenzar.

Node.js (>= v18.0.0)

Requerido para ejecutar el entorno de backend Express y los scripts de scaffolding de Vite.

node -v # v18+, v20+ o v24+ LTS

MongoDB Service

Servicio local activo en puerto 27017. Se conectará automáticamente a dstack-db.

mongod # mongodb://127.0.0.1:27017/dstack-db

npm (>= v9.0.0)

Gestor de paquetes predeterminado para la instalación del CLI global dstack y dependencias.

npm -v # v9+ o v10+

Diseñado para la Excelencia

Arquitectura por Capas

Separación limpia y desacoplada entre Rutas (Routes), Controladores (Controllers), Servicios (Services) y Modelos (Models).

Middleware listo para usar que valida esquemas de cuerpo, parámetros y consultas HTTP devolviendo errores estandarizados.

Guía de Inicio Rápido

Comienza en 3 sencillos pasos.

1

Instalar CLI Globalmente

Instala dstack directamente desde npm:

npm link dstack
2

Crear un Proyecto Monolítico

Genera la estructura de backend API (Express + Mongo) y frontend React (Vite):

dstack init mi-gran-app
3

Scaffold de Componentes & Iniciar

Genera recursos completos y corre el servidor de desarrollo en simultáneo:

cd mi-gran-app
dstack g resource Product
npm run dev
